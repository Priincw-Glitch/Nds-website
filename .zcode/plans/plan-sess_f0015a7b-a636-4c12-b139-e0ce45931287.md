# Dropdown Cakupan Wilayah Admin — Provinsi → Kota/Kabupaten → Kecamatan (Seluruh Indonesia)

## Context

Form Tambah/Edit Cakupan Wilayah di Admin Panel masih memakai input teks bebas untuk Provinsi/Kota/Kabupaten/Kecamatan. Target: tiga dropdown bersambung yang bisa dicari, berisi seluruh wilayah Indonesia dari tabel referensi lokal (tanpa API eksternal saat dropdown dibuka), tervalidasi di backend, tanpa menghapus data lama dan tanpa merusak fitur publik Cek Jangkauan.

Eksplorasi: model `ServiceCoverage` (area_name, city, district, province — nama bebas), form add+edit inline di `Admin/Coverages/Index.tsx`, publik `CoverageController@check` memakai pencarian LIKE atas nama wilayah. Belum ada tabel wilayah; belum ada combobox searchable (hanya `ui/select.tsx` tanpa pencarian).

Sumber data (terverifikasi live): **emsifa/api-wilayah-indonesia v2** — `provinces.json` (38 provinsi ✓ pasca pemekaran Papua), `regencies/{kode}.json` (514), `districts/{kode}.json` (±7.266); kode Kemendagri (11 / 11.01 / 11.01.01), nama proper-case dengan prefix "Kabupaten"/"Kota".

## 1. Database (migration baru, aditif — data lama utuh)

`database/migrations/2026_11_07_000002_create_indonesia_region_tables.php`:
- `indonesia_provinces`: `code char(2) PK`, `name`
- `indonesia_regencies`: `code char(4) PK`, `province_code char(2)` (+index, FK), `name`
- `indonesia_districts`: `code char(6) PK`, `regency_code char(4)` (+index, FK), `name`
- `service_coverages` += nullable `province_code char(2)`, `regency_code char(4)`, `district_code char(6)` + index (kolom nama lama tetap; baris lama tanpa kode tetap valid)

## 2. Seeder (pilihan user: unduh otomatis)

`database/seeders/IndonesiaRegionSeeder.php`:
- Fetch berurutan: provinces.json (1×) → untuk tiap provinsi regencies/{code}.json (38×) → untuk tiap kab/kota districts/{code}.json (514×) via `Http::retry(3)->timeout(30)`; kode dinormalisasi (titik dihapus: "11.01" → "1101").
- Upsert per chunk (`updateOrCreate` berdasarkan code) → aman dijalankan ulang, tidak ada duplikat.
- Log ringkas jumlah impor: 38 / 514 / ±7.266.
- Dijalankan user: `php artisan db:seed --class=IndonesiaRegionSeeder` (butuh internet hanya saat seeding).

## 3. Models & API backend

- Model ringkas: `IndonesiaProvince`, `IndonesiaRegency`, `IndonesiaDistrict`.
- Routes (di dalam grup `admin.coverages`, middleware auth+admin yang sudah ada):
  - `GET admin/coverages/regions/provinces`
  - `GET admin/coverages/regions/regencies/{provinceCode}` (whereAlphaNumeric)
  - `GET admin/coverages/regions/districts/{regencyCode}`
  - Respons: `[{code, name, type}]` — `type` kota|kabupaten didapat dari prefix nama ("Kota " → kota, selainnya kabupaten).
- `CoverageAdminController@store/update`: terima `province_code` (required), `regency_code` (required), `district_code` (required); **validasi relasi di backend** — regency harus milik province, district harus milik regency (query tabel referensi, 403/422 bila tidak cocok); **nama city/district/province diambil dari tabel referensi** (bukan dipercaya dari frontend); kolom nama lama tetap terisi sehingga Cek Jangkauan publik (LIKE) bekerja tanpa perubahan.

## 4. Frontend

- **Komponen baru `resources/js/Components/admin/RegionCombobox.tsx`** — combobox searchable bergaya Admin Panel (trigger memakai style `.input`, popover putih rounded + shadow-dropdown, ikon ChevronDown, item hover `bg-navy/5`, fokus ring tech-blue): input pencarian memfilter klien-side (data per level ≤ ~100 baris, instan), keyboard ↑/↓/Enter/Escape, klik-luar menutup, loading spinner saat fetch, pesan "Tidak ditemukan", disabled sebelum induk dipilih, `aria-expanded/activedescendant`.
- **`Admin/Coverages/Index.tsx`**: ganti 3 input teks (provinsi/kota/kecamatan) dengan 3 RegionCombobox bersambung:
  - Ganti provinsi → reset kota & kecamatan (fetch regencies); ganti kota → reset kecamatan (fetch districts).
  - Badge jenis wilayah (Kota/Kabupaten) pada opsi kota/kabupaten.
  - Edit: prefill by `province_code/regency_code/district_code`; baris lama tanpa kode → cocokkan by nama (exact, case-insensitive); bila tak cocok → kosong (admin memilih ulang), data lain tidak hilang.
  - Form mengirim kode + nama; `area_name`, layanan, status, catatan, is_active tidak berubah.
- Fitur Cek Jangkauan publik & `CoverageCheckSection` tidak diubah (nama wilayah tetap tersimpan di kolom yang sama).

## 5. Verifikasi

Dijalankan user (Bash tetap mati di environment ini):
1. `php artisan migrate` → cek 3 tabel + kolom kode.
2. `php artisan db:seed --class=IndonesiaRegionSeeder` → laporkan 38/514/±7.266.
3. `npm run build`.

Saya verifikasi via browser (kredensial admin sudah ada): alur tambah (pilih provinsi → kota → kecamatan → simpan), pencarian tiap dropdown, reset otomatis saat induk berubah, edit data lama (prefill + ubah wilayah), data tersimpan & tampil kembali, Cek Jangkauan Beranda tetap menemukan wilayah yang disimpan, dan tidak ada kombinasi wilayah lintas induk (coba paksa via API → ditolak backend).
