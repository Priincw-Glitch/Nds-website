## SETUP WEBHOOK TAWK.TO → ADMIN WEBSITE

Chat log Tawk.to otomatis masuk ke halaman **Pesan Admin** website via webhook real-time.

### Langkah Setup (sekali saja):
1. Buka [dashboard.tawk.to](https://dashboard.tawk.to)
2. Klik **Admin** (ikon ⚙️) → cari menu **Webhooks**
3. Klik **Create Webhook**
4. Isi:
   - **Webhook URL:** `https://domain-anda.com/webhooks/tawk` (ganti dengan URL produksi Anda)
   - **Events:** pilih `Chat Start`, `Chat End`, `Chat Transcript`
   - **Secret Key:** copy value-nya → simpan di `.env` sebagai `TAWK_WEBHOOK_SECRET`
5. Klik **Save**

### Alur data:
- `chat:start` → buat pesan baru di admin (status: belum dibaca)
- `chat:transcript` → update pesan dengan transcript lengkap (visitor + agent)
- `chat:end` → buat record jika belum ada

### Untuk development lokal:
Gunakan [ngrok](https://ngrok.com) untuk expose port 8000, lalu pakai URL tunnel tersebut sebagai Webhook URL di dashboard Tawk.to.
