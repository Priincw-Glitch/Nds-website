# Audit 001 — anti-slop — 2026-10-22

Scope: halaman publik (Home, About, ServiceDetail, Promo, Blog, Contact, Privacy, NotFound) + Navbar, Footer, ServiceCard, SectionHeading, app.css.

Prioritas mengikuti tier rule: Hard Gate = HIGH, Purpose-Gate = MEDIUM, Quality Locks = LOW.

## Findings

1. **[HIGH] R-02 — Em dash (—) dalam teks.**
   Ditemukan di: `app.tsx:11` (pemisah title browser), `Seo.tsx:13,24`, `Home.tsx:59` (meta description), `About.tsx:32` (fallback description), ~14 file admin (`Head title="X — NDS Admin"`), `Articles/Form.tsx:56` (option "— Tanpa kategori —"). Ganti dengan koma/titik/kolon atau separator lain.

2. **[HIGH] R-25 — Kontras teks gagal WCAG AA.**
   Badge `text-crimson` di atas `bg-crimson/10` ≈ 3.9:1 (butuh 4.5): Home promo "Berakhir {tanggal}" (Home.tsx:328), badge promo (Promo.tsx:81). Label placeholder `text-navy/40` di gradient blog ≈ 2.2:1 (Home.tsx:383).

3. **[HIGH] R-38 / R-28 — FAQ jawaban palsu.**
   `ServiceDetail.tsx:142` — semua pertanyaan FAQ dijawab identik "Hubungi tim NDS untuk diskusi lebih lanjut mengenai kebutuhan Anda." Jawaban boilerplate yang menyamar jadi konten nyata. Isi jawaban asli per layanan, atau hapus FAQ selama jawaban belum ada.

4. **[HIGH] R-36 — Tanggal "Terakhir diperbarui" selalu hari ini.**
   `Privacy.tsx:27` — tanggal dihitung `new Date()` setiap render, jadi kebijakan selalu terlihat "diperbarui hari ini" walau tak pernah diubah. Pakai tanggal statis yang diedit manual.

5. **[MEDIUM] R-01 — Glow blob identik di hero setiap halaman.**
   `bg-tech-blue/20 blur-3xl` yang sama muncul di About:36, Promo:27, Contact:41, ServiceDetail:38, dan CTA Home:412. Orb dekoratif default tanpa tujuan berbeda antar halaman. Pertahankan di satu tempat (identity motif) atau hilangkan; kalau tetap, tulis tujuannya.

6. **[MEDIUM] R-14 — Kartu/row identik.**
   `Home.tsx:19-40` — 4 baris "advantage" persis sama: ikon CheckCircle2, ukuran, padding identik. `About.tsx:102` — 3 kartu nilai grid seragam tanpa hierarki.

7. **[MEDIUM] R-04 — Ikon generik tanpa relevansi tertulis.**
   CheckCircle2 dipakai ulang untuk advantages, pendekatan About, dan semua item manfaat (ServiceDetail). Set ikon lucide dipilih default, bukan karena relevansi konten.

8. **[MEDIUM] R-08 — Panah (→) dekoratif di hampir semua tombol.**
   ArrowRight muncul di hero x2, semua link section, CTA, kartu layanan, artikel — sebagai default, bukan karena tujuan. Tanpa alasan tertulis.

9. **[LOW] R-15 — CTA generik.**
   "Learn More About Us" (Home:209,259), "Contact Our Team" (Home:424, About:126, ServiceDetail:191), "Selengkapnya" (ServiceCard:24), "Ready to Build Your Next Digital Solution?" (Home:416). Belum spesifik konteks produk.

10. **[LOW] R-20 — Bahasa campur ID/EN merusak identitas.**
    Nav "About / Contact Us / Privacy Policy", eyebrow "Why Choose NDS / Featured Projects", judul CTA Inggris di situs berbahasa Indonesia. Konsistensi bahasa belum dijalankan dari atas ke bawah.

11. **[LOW] R-05 — Ritme section seragam + footer template.**
    Services, Projects, Promo, Blog di Home semua komposisi "SectionHeading + grid 3 kolom". Footer 4-kolom (Navigasi/Layanan/Kontak) mendekati pola template yang dilarang.

12. **[LOW] R-32 — Indikator fokus input lemah.**
    `app.css:249` — `.input:focus { outline: none }` hanya mengganti warna border (tipis). Tombol sudah benar (`:focus-visible` outline). Nav/kartu memakai outline browser default (lolos).

## Lolos (tidak ditemukan pelanggaran)

- R-17/R-36: tidak ada statistik/fake numbers — section "angka" Home menampilkan kategori layanan nyata.
- R-18: tidak ada testimoni palsu (dan tidak ada section testimoni — benar).
- R-24/R-26: semua link nav & tombol punya tujuan nyata (route()/#services/mailto) — tidak ada kontrol mati.
- R-27: empty state ada di Promo, Blog, dan semua tabel admin; form punya state processing + error.
- R-16: tidak ditemukan buzzwords (Seamless/Revolutionary/AI Powered/dll).
- Placeholder portofolio di Home jujur disebut "masih placeholder" (R-38 dipatuhi).

## Fix log — 2026-10-22 (semua nomor disetujui)

1. Em dash dihapus dari semua meta/title/teks (separator sekarang `|`, deskripsi pakai koma, option kategori pakai kurung).
2. Badge `bg-crimson/10` → teks `text-crimson-dark` (≈5.0:1 lolos AA) di Home/Promo/Pesan admin; label placeholder `text-navy/40` → `text-navy/70` (≈5.3:1) di Home/Blog/BlogDetail.
3. FAQ ServiceDetail: parser baru mendukung format `Pertanyaan || Jawaban`; item tanpa jawaban asli tidak dirender (FAQ hilang sampai admin isi jawaban nyata); label form admin diperbarui.
4. Privacy: tanggal "Terakhir diperbarui" jadi statis "22 Oktober 2026"; judul → "Kebijakan Privasi".
5. Glow blob `blur-3xl` dihapus dari hero About/Contact/Promo/Blog/BlogDetail/ServiceDetail; hanya satu tersisa di CTA Home (light source untuk CTA).
6. Advantages Home: judul diterjemahkan ke ID, item pertama jadi kartu navy featured (hierarki); 3 kartu "Nilai" About jadi strip kolom terpisah garis (bukan grid kartu identik).
7. Ikon: CheckCircle2 seragam diganti Puzzle/Headphones/Server/Handshake (relevan per item); daftar manfaat/about pakai bullet titik.
8. ArrowRight/ChevronRight dekoratif dihapus dari semua tombol/link (sisa: panah kiri "Kembali ke Blog" & Home icon 404 = tujuan jelas).
9. CTA generik diganti: "Kenali cara kerja kami", "Lihat profil NDS", "Mulai Konsultasi Gratis", "Jadwalkan Konsultasi Gratis", "Konsultasikan Layanan Ini", "Lihat detail {layanan}".
10. Bahasa diseragamkan: nav/footer "Tentang Kami / Hubungi Kami / Kebijakan Privasi", dropdown "Aplikasi/Solusi", eyebrow "Mengapa NDS/Tentang NDS", judul "Proyek Unggulan", CTA "Siap Membangun Solusi Digital Berikutnya?".
11. Ritme Home: Proyek → daftar baris horizontal; Promo → baris strip; Blog/Layanan tetap grid kartu (kartu berbeda fungsi); footer jadi grid asimetris 5/3/4 dengan kolom Kontak di dalam brand column.
12. `.input:focus` kini punya outline 2px + ring 25% alpha; `btn-outline-light` ditambahkan ke aturan `:focus-visible`.

Verifikasi: `tsc --noEmit` exit 0, `npm run build` sukses, semua route publik 200 (404 benar), bundle bersih dari copy lama.
